# RoyalBet Palace

Sito di gioco d'azzardo con schedine calcio e corse di cavalli.

## Tecnologie
- HTML5
- CSS3
- JavaScript

## Come si gioca
1. Apri `index.html` nel browser
2. Scegli la sezione: Schedine Calcio o Corse Cavalli
3. Seleziona un esito o un cavallo
4. Inserisci la puntata
5. Clicca GIOCA
